Demo policies & boundaries

  1. Tracking and cancellation decisions run in service code.
  2. Chat receives a tenant header. This playground does not authenticate customers.
  3. The foreign AWB scenario exercises ownership checks. The sandbox inspector itself is not private.
  4. Model tool execution is bounded by the backend.
  5. Handoffs are queued in the demo outbox; no human agent is connected here.

State is shared in memory and resettable. WhatsApp is a channel simulation here, not a connected business account. Product artwork is illustrative. These are not production security or delivery guarantees.
